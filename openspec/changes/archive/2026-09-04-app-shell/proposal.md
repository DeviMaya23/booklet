## Why

The authenticated `/app` route currently renders an empty placeholder. This change builds the app shell — the persistent top bar and collapsible sidebar that frame all authenticated views — and establishes the subroute structure for Characters, Images, and Artists.

## What Changes

- Initialize shadcn (Base UI style) to enable component installation from the registry
- Install the shadcn sidebar block (`base-` style, backed by `@base-ui/react`)
- New `AppShell` component: top bar (wordmark + user avatar/logout) + collapsible sidebar + content outlet
- Sidebar nav with three sections: Characters, Images, Artists
- Three stub pages: `CharactersPage`, `ImagesPage`, `ArtistsPage` (render null, ready for future content)
- `/app` redirects to `/app/characters`; child routes wired under `AppShell`

## Capabilities

### New Capabilities

_(none)_

### Modified Capabilities

- `web-app-shell`: The shell at `/app` now renders a full authenticated layout — top bar with branding and user controls, collapsible sidebar navigation, and a content area for subroutes. Routes `/app/characters`, `/app/images`, and `/app/artists` are introduced as stub destinations.

## Impact

- **New files**: `src/components/ui/sidebar.tsx` (generated by shadcn), `src/components/AppShell.tsx`, `src/components/AppTopBar.tsx`, `src/components/AppSidebar.tsx`, `src/pages/CharactersPage.tsx`, `src/pages/ImagesPage.tsx`, `src/pages/ArtistsPage.tsx`, `frontend/components.json`
- **Modified files**: `src/App.tsx` (nested routes + redirect), `openspec/specs/web-app-shell/spec.md` (requirements expanded)
- **Removed files**: `src/pages/AppPage.tsx`
- **Dependencies**: no new npm packages; shadcn generates components from existing `@base-ui/react` and `lucide-react`
- **No breaking changes** to existing routes or auth flow
